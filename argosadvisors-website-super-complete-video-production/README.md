# Argos Advisors — Super Complete Video Production Website

A rebuilt static website for a video strategy, production and post-production studio.

## Core improvements
- Removed generic SaaS/local-business language.
- Rebuilt catalog around 36 real production services/programs.
- Added service search/filtering and a local Production Brief builder.
- Added dedicated Strategy, Production, Post, Specialty, Programs, Work, Cases, Process, Capabilities, Studio and Pricing pages.
- Removed banquet/event imagery and generic abstract filler.
- Kept only production-relevant imagery, optimized to WebP.
- Demo pricing and contact data are clearly marked as prototype content.

## Verify before production
- Real contact details
- Actual city/studio facilities
- Legal terms and privacy
- Real portfolio/client work
- Real pricing and usage/licensing terms
- Real form/CRM endpoint
